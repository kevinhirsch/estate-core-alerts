Estate Core Alerts

A text-message notification program operated by Kevin Hirsch.

Estate Core is server-automation software developed and operated by Kevin Hirsch, an independent software developer. Estate Core Alerts sends its registered users automated text messages about their own server: alerts when something needs attention, and a short status summary each morning and evening.

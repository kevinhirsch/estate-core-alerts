Estate Core Alerts text-message program. Effective November 11, 2026.

1. Program name and description

Estate Core Alerts is a text-message (SMS) notification program operated by Kevin Hirsch, an independent software developer and sole proprietor ("we", "us"). The program sends automated, transactional messages to registered users of the Estate Core server-automation software who have opted in. Messages are system alerts (for example a stalled job or a request waiting for approval) and two daily status summaries. The program sends no marketing or promotional messages.

2. How to opt in

Text START to +1 (947) 777-7408. You will receive a confirmation message. By opting in you agree to receive recurring automated text messages from Estate Core Alerts at the mobile number you texted from. Consent is not a condition of any purchase.

3. Message frequency

Message frequency varies with system activity, up to 4 messages per day.

4. Message and data rates

Message and data rates may apply, according to your mobile plan. The program itself is free.

5. How to opt out (STOP)

Reply STOP to any message to cancel. You will receive one final message confirming that you are unsubscribed, and no further messages will be sent. To rejoin, text START to +1 (947) 777-7408.

6. Help (HELP) and support contact

Reply HELP to any message for help, or text +1 (947) 777-7408.

Mobile carriers are not liable for delayed or undelivered messages. Delivery depends on your carrier and device.
